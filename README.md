# indexhex

Index encode/decode helpers for hex payloads in pipelines.

**Site:** https://theworker02.github.io/indexhex/

## Install / run

```bash
git clone https://github.com/theworker02/indexhex.git
cd indexhex
node src/cli.js
node --test
```
